### Overview

The Open Modeling Framework (OMF) is a set of Python libraries for simulating power systems behavior with an emphasis on cost-benefit analysis of emerging technologies: distributed generation, storage, networked controls, etc.

Full [OMF documentation](./omf/docs/README.md) is available.

### Installation

Anyone can sign up for a free account on our hosted production site https://omf.coop/.

You can install the software locally by running `pip install git+https://github.com/nreca-bts/omf` or you can use one of our dockerfiles in this directory.
